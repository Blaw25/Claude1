Automatic Sync (Google Drive)

Keeps every device in sync automatically through your own Google Drive — it loads your latest data when you open the app and saves quietly as you make changes. One-time setup below.

Status: Not connected Last synced: never
One-time setup: get your Google Client ID (~10 min)
  1. Go to console.cloud.google.com and create a project (any name).
  2. APIs & Services → Library: search Google Drive API and click Enable.
  3. APIs & Services → OAuth consent screen: choose External, enter an app name and your email, save. Under Test users, add your own Google email.
  4. APIs & Services → Credentials → Create Credentials → OAuth client ID. Application type: Web application.
  5. Under Authorized JavaScript origins add: https://blaw25.github.io
  6. Click Create, copy the Client ID, paste it above, tap Save ID, then Connect Google Drive.

The Client ID isn't a secret. Your financial data is stored only in your own Google Drive (in a file named budget-sync.json); this app can't see any of your other Drive files.

Manual Backup

Optional. A one-off backup file you can move yourself (iCloud Drive, AirDrop, email). Handy even if you use automatic sync above.

Last backup: never Last restore: never
How to sync with iPhone + computer
  1. On the device you just edited, tap Back Up.
  2. Choose Save to Files → iCloud Drive (pick the same folder each time), or AirDrop it straight to your Mac.
  3. On the other device, open this app and tap Restore from File, then pick that file.

Tip: always Back Up after making changes, and Restore before viewing on the other device, so you don't overwrite newer data.
